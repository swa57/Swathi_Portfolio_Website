# Swathi K – Personal Portfolio

A sleek, dark-themed personal portfolio website for AI/ML Engineer Swathi K.

## 📁 Project Structure

```
swathi-portfolio/
│
├── index.html          ← Main portfolio page
├── style.css           ← All styles
├── script.js           ← Interactions & lightbox
├── README.md           ← This file
│
└── certificates/       ← 📸 ADD YOUR CERTIFICATE IMAGES HERE
    ├── iit-madras.jpg
    ├── azure-data-scientist.jpg
    ├── upgrad-aiml.jpg
    ├── upgrad-ds.jpg
    └── google-kaggle-ai-agents.jpg
```

## 🚀 How to Use

1. Open `index.html` in any modern browser — no server needed!
2. Add your certificate images to the `certificates/` folder.

## 📸 Adding Certificates

Each certificate card in the **Certifications** section is clickable and opens a lightbox.

Save your certificate images with these **exact filenames** in the `certificates/` folder:

| Certificate | Filename |
|---|---|
| IIT Madras | `iit-madras.jpg` |
| Azure Data Scientist | `azure-data-scientist.jpg` |
| UpGrad AI/ML | `upgrad-aiml.jpg` |
| UpGrad Data Science | `upgrad-ds.jpg` |
| Google & Kaggle AI Agents | `google-kaggle-ai-agents.jpg` |

> **Supported formats:** `.jpg`, `.jpeg`, `.png`, `.pdf` (use `.jpg` for best results)

## ✏️ Customization

- Edit `index.html` to update any content
- Edit `style.css` to change colors (CSS variables at the top of the file)
- To change accent color: update `--accent: #7c6bff;` in `:root`

## 🌐 Hosting (Optional)

To host this online for free:
- **GitHub Pages**: Push to a GitHub repo → Settings → Pages → Deploy from branch
- **Netlify**: Drag & drop the folder at netlify.com/drop
- **Vercel**: Install Vercel CLI and run `vercel`
